# Billine Web

Frontend application for Billine product workflows.

## What this repository contains
- React-based web interface
- Client-side business flow implementations
- Standard frontend build/test scripts

## Tech stack
- React
- TypeScript
- npm

## Project structure
- `src/` - application source code
- `public/` - static assets

## Getting started
```bash
npm install
npm start
```

## Build and test
```bash
npm run build
npm test
```
